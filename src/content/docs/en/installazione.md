# First Login and Initial Setup

This guide describes the steps required to start using Fibonacci from the first login to the complete setup of your practice. It is aimed at the practice owner or the administrative contact who first receives the invitation email.

At the end of the procedure, the practice will have an administrative account protected by two-factor authentication, a complete practice profile, and the first operators invited. The average time required is about fifteen minutes.

## Prerequisites

- Invitation email received at the address provided during the commercial onboarding phase.
- Updated supported browser: Chrome, Edge, Safari, or Firefox in the latest version.
- Smartphone with an **authenticator** app installed: `Google Authenticator`, `Authy`, `1Password`, or `Microsoft Authenticator`.
- Practice logo file in PNG format, recommended size 512 x 512 pixels, transparent background.
- Practice tax details: legal name, VAT number, practice address, public contact information.

## Step 1, Access via Invitation Link

The invitation email comes from a system address, with the subject `Invitation to Fibonacci`. It contains a unique link valid for forty-eight hours.

Open the link in a new browser tab. If the link has expired, request a new invitation via {EMAIL_SUPPORTO}.

The first screen asks you to confirm your email address and set a personal password. The password must meet the following minimum requirements:

- at least twelve characters,
- at least one uppercase and one lowercase letter,
- at least one number,
- at least one special character among `! @ # $ % & * ?`.

Passwords are checked against public lists of compromised credentials. A weak or reused password will be rejected with an explicit message.

## Step 2, Enabling TOTP MFA

MFA, or **Multi-Factor Authentication**, is two-factor authentication: in addition to the password, a temporary code generated by the authenticator app on your smartphone is required. Activation is mandatory for all accounts accessing health data.

The guided procedure displays a QR code. Open the authenticator app on your smartphone, select `Add` or equivalent, and scan the QR code. The app adds a new entry labeled `Fibonacci - email@example.com` and starts displaying a six-digit numeric code that refreshes every thirty seconds.

Enter the current code in the verification field and confirm. Validation is immediate: if the code is correct, the app receives confirmation of MFA activation.

## Step 3, Recovery Codes

Immediately after enabling MFA, Fibonacci generates ten single-use **recovery codes**. Each code can be used only once instead of the TOTP code in case of smartphone loss.

Print the page or download the displayed PDF file. Store the codes in a secure physical location, separate from your smartphone. Do not save them on the same device that generates the TOTP codes.

When a recovery code is used, it is marked as consumed. When fewer than three unused codes remain, the application displays a warning to generate new ones.

## Step 4, Practice Profile

After completing the first login, the application opens the `Settings > Organization` screen. The mandatory fields are:

- **Legal name**, the legal name of the practice or the professional’s first and last name.
- **Italian VAT number**, eleven digits, automatically validated for format.
- **Tax code** of the practice or the owner.
- **Practice address**: street, number, postal code, city, province.
- **Public contact information**: practice phone number, public email, optional website.

Optional fields include the registration number with the Ordine dei Medici, the main specialization, and opening hours.

The practice logo is uploaded using the `Upload logo` button. The system accepts PNG and JPEG files up to two megabytes and automatically resizes the image to 512 x 512 pixels while maintaining proportions. The logo appears on receipts, consents, and patient messages.

## Step 5, Inviting Operators

From the `Settings > Users` panel, the `Invite user` button opens a modal with the following fields:

- operator’s first and last name,
- business email,
- role,
- optional specialty.

The available roles are:

- **Practice Admin**, full access to all areas including settings and audit log.
- **Physician**, clinical access to assigned patients or the entire practice based on configuration, full access to medical records, visits, dictation, and consents.
- **Receptionist**, access to the schedule and patient registry, read-only access to clinical data, no access to the audit log.

Each invited operator receives their own invitation email with the same procedure described in steps one to three. Upon first login, the operator sets their personal password and MFA.

The maximum number of operators depends on the subscribed plan. The panel shows current usage and the plan limit.

## Tips

- Create a dedicated administrative account right away, separate from the clinical physician account, for management-only operations.
- Print the recovery codes in two copies and store one outside the practice.
- Set up the logo before generating consents: previously generated PDFs are not updated retroactively.
- Verify tax details with your accountant before saving: they appear on receipts and invoices.

## Troubleshooting

**The TOTP code is invalid.** Ensure your smartphone’s time is automatically synchronized with the network. A time drift of more than thirty seconds invalidates TOTP codes. On iOS, go to `Settings > General > Date & Time > Set Automatically`. On Android, go to `Settings > System > Date & Time > Automatic date & time`.

**The invitation link has expired.** Links are valid for forty-eight hours. Request a new invitation via {EMAIL_SUPPORTO}, specifying the recipient email.

**Recovery codes lost and smartphone unavailable.** Contact support. The procedure involves verifying the practice owner’s identity with an ID document and subsequent MFA reset. The reset may take up to twenty-four working hours.

**Error during logo upload.** Verify that the file is in PNG or JPEG format and does not exceed two megabytes. Files with CMYK color profiles or complex transparencies are sometimes rejected: save the file in sRGB PNG and retry the upload.
